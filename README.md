One word an agent says when it has no idea what to do: **Welp** — the verbal shrug, defeat accepted with a grin. Funny at once, instantly understood, honest: no bluffing, no stalling, just "welp".

## Run it

```sh
python3 main.py
```

Writes the single word to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (default `/output`). Pure Python standard library; no network, no third-party packages.
